# IEDC Certificate Generator & Verification System

An automated web application designed to generate, template, and verify event certificates for Innovation and Entrepreneurship Development Centre (IEDC) activities.

## 🚀 Features

* **Certificate Generation:** Create customized certificates dynamically using `generator.html`.
* **Template Management:** Select and preview various design layout templates via `templates.html`.
* **Bulk Processing:** Import participant data directly using CSV files (`sample.csv`).
* **Verification System:** Validate certificate IDs using automated JS/Excel verification logic.
* **GitHub Pages Integration:** Hosted directly on GitHub Pages for fast and reliable access.

## 📦 Getting Started

### Local Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Steny005/iedc-certificates.git](https://github.com/Steny005/iedc-certificates.git)

```

2. **Navigate to the project directory:**
```bash
cd iedc-certificates

```


3. **Run locally:**
Open `index.html` or `generator.html` directly in any standard web browser.

### Bulk Generating Certificates

1. Prepare a `.csv` file following the format in `sample.csv`.
2. Open `generator.html`.
3. Upload your CSV file to auto-populate participant details and export generated certificates.
