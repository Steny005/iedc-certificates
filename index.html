Offline Certificate Management System

A completely offline system for designing certificate templates, mapping Excel data, generating QR verification codes, and batch rendering certificates.

Template Manager → Generate Certificates →

PAGE 1: TEMPLATE MANAGER

Upload custom PNG/JPG certificate background images. Perform rule-based offline validation (minimum 1600 × 1100 px landscape), configure field positions (Name, Description, Date, QR Code, Verification ID) using the visual drag-and-drop editor, and save templates locally.

  • Offline rule-based image validation
  • Drag-and-drop field positioning canvas
  • Font size, family, color & alignment customization
  • Required field checklist validation
  • IndexedDB local template storage
Open Template Manager

PAGE 2: CERTIFICATE GENERATOR

Select any saved template, choose certificate wording logic (Participation, First Prize, Second Prize, Contribution), upload Excel/CSV files with automatic or custom column mapping, and batch render high-resolution certificates.

  • Preserves exact wording logic (Participation, Prizes, Contribution)
  • Offline Excel (.xlsx) & CSV file parsing
  • Auto-detection & manual column header mapping
  • Unique verification ID & offline QR code generation
  • Download individual PNG/PDF or batch ZIP bundle
